(1) In ./test 3, allocations fail because new_free() doesn't coalesce adjacent free blocks. This causes external fragmentation, where there isn't a single block large enough for a request up to 128-bytes even though multiple smaller free blocks combined would be enough.
(2) For throughput, t.out has better throughput for smaller byte sized allocations and then plateaus for larger allocations. At larger allocations, t2.out has a better throughput. This makes sense, because for smaller bytes, t.out isn't coalescing which makes it operate faster. For larger byte allocations, coalescing allows t2.out to continue to successfully allocate memory.
(3) For fail rate, t2.out has a much better failrate that is consistently at 10%. This is because of coalescence. Since t.out is missing coalescence, it has trouble allocating memory to large byte blocks.
